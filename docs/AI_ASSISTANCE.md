# AI assistance

OpenAI Codex was used to implement the Python service, browser UI, tests and
documentation. Official OpenAI documentation was consulted for Responses web
search, source metadata and Pydantic Structured Outputs. No agent framework or
delegated coding agents were used.

Automated tests use mocked provider outputs and fictional example.com evidence.
They exercise code behavior, not the quality of real news. See TESTING.md for
actual verification and its limits. AI-generated code and prompts require human
review. The submitting author should read and understand every significant line
and be able to modify the app without AI during the interview.
